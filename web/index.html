Four simple steps.

01

Clean the input

We check that the DNA uses valid letters and that the guide has 20 bases.

02

Find possible sites

We look on both DNA strands for an NGG pattern, a short signpost for a possible CRISPR target.

03

Compare the match

We count where the guide and each possible site are different.

04

Explain the score

Differences near the PAM matter more, so those sites receive a lower score.

03 · ABOUT

Made to make a complex idea easier to see.

CRISPR is a tool scientists use to guide changes in DNA. This project focuses on one question: could the guide also match somewhere else? It is a learning tool, not a medical recommendation.
