03 · HOW IT WORKS

Four steps, clearly explained.

01

Validate the input

We confirm that the DNA uses valid bases and that the guide is 20 bases long.

02

Scan both strands

We find candidate spacers next to an NGG PAM, a required pattern for this SpCas9 model.

03

Count mismatches

We compare each candidate with the guide and record exactly where they differ.

04

Apply the score

Mismatches near the PAM-proximal seed are weighted more heavily in the heuristic score.

04 · ABOUT

A clearer way to inspect potential off-targets.

CRISPR-Trace is an educational project built around one question: where else might a guide sequence match? It makes the comparison visible without hiding the reasoning behind a single number. It is not a clinical predictor or a substitute for experimental validation.
